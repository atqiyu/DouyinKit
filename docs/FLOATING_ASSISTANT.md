# Kit 浮球（悬浮球）实现与使用

## 定位

“Kit 浮球”是 DouyinKit 的可选前台辅助功能，用于在抖音/抖音极速版中快速解析当前作品。
它坚持纯本地：不读取账号、不上传页面内容、不绕过验证码，只完成“复制分享链接 → 本机解析 →
按默认值下载”的个人操作。仅在用户明确开启、授予悬浮窗和无障碍权限后运行。

## 两种模式

### 轻享模式（原普通模式）

- 点击浮球后，操作按钮环绕浮球弹出；浮球本体保留。可读取剪贴板中的抖音链接，点击“解析剪贴板”回到 DouyinKit 的解析页。
- “输入链接”和“打开 App”使用图标按钮；输入通过悬浮输入框完成。
- 连播模式只有一个“分析当前视频”入口，避免重复按钮歧义。
- 当检测到新的抖音链接时，浮球会变为粉色圆点并自动弹出解析提示；只提示，不自动下载。
- 不依赖无障碍服务；但未开启无障碍时无法识别“抖音是否在前台”，状态会显示为未知/其他应用。

### 连播模式（原超级模式）

- 需要无障碍服务。点击“分析当前视频”后，浮球通过无障碍节点找到抖音右下角的“分享”按钮并点击，
  再在分享面板中点击“分享链接”，随后从剪贴板取得链接。
- 解析在悬浮球内部的 1×1 隐藏 WebView 中完成，**不会切回 DouyinKit**；面板显示解析阶段、
  作品标题、队列和下载进度。
- 若开启了“连播自动下载”，解析完成后按现有下载默认值自动入队下载：
  - 视频：默认清晰度（含“最高清晰度”），不自动下载封面；
  - 图文：按设置中的 LivePhoto/BGM/ZIP 默认开关；
  - 自动下载前做本地重复检查，重复内容自动跳过。
- 当前作品还没解析/下载完时点“下一个”，新作品进入等待队列；当前作品完成后自动开始下一个。
  队列只保存在进程内，服务被杀后需要重新分享。
- 遇到滑块/拼图等安全验证时，浮球会自动展开同一个解析 WebView 让用户完成；登录页只提示，
  不自动展开。验证码不能绕过。

## 浮球界面

- **状态点**：只表示前台应用。绿色 = 抖音/抖音极速版在前台；灰色 = 桌面、DouyinKit 或其他应用。
  无障碍服务未开启时显示空心灰环，表示无法判断前台；打开/关闭浮窗不会改变状态点。
  前台判断以无障碍的活动窗口为准，并对高频内容变化事件做 800ms 节流，避免桌面出现残留绿色。
- **模式徽标**：浮球图标底部显示“轻”或“连”，不再在浮窗里重复显示模式。
- **进度环**：浮球外圈在解析等待时旋转扫描，下载时显示真实百分比进度；空闲时隐藏。
- **操作环**：全部按钮为 42dp 纯图标，不显示文字；默认“分析当前视频”在浮球正上方，
  输入在左、打开在右，停止/结果在下方按状态出现。按钮距离（0–24dp）和整体旋转（-60°–60°）
  可在设置中调整。没有“下一个”按钮；队列繁忙时“分析当前视频”仍显示，点击会继续自动分享并加入队列。
- **边缘与休眠**：浮球可以拖到屏幕边缘并部分露出；点击边缘浮球会平滑移回按钮环安全位置再展开操作环。
  默认 45 秒无操作后，浮球移到最近边缘并降低透明度；点击唤醒、移回安全位置并展开操作环。
  解析/下载、操作环、输入框或浮窗打开时不休眠。
- **信息浮窗**：与浮球分离，可独立拖动和调整大小；默认 280×112dp，边距缩小，可缩到约 150×64dp，
  最小宽高可在设置中调整。背景由 `FrostedPanelDrawable` 在面板内部绘制，
  支持毛玻璃/半透明/完全透明/纯色、不透明度和色调设置；磨砂强度只改变面板自身的纹理，
  不请求系统跨窗口模糊，因此不会模糊屏幕其他区域（部分 OEM 会把 `FLAG_BLUR_BEHIND` 应用成整屏模糊）。
- 浮窗文字精简：不显示 Kit 浮球标题、抖音状态、模式或下载作品标题；只显示执行状态/提示、
  进度、队列和可选剪贴板内容。剪贴板显示可在设置关闭。

## 架构

```
FloatingAssistantService（前台服务，specialUse）
  ├─ WindowManager 悬浮球 + 环绕操作窗口 + 独立信息浮窗 + 输入框
  ├─ ClipboardManager 监听 + ClipboardFocusReader（后台剪贴板补救）
  ├─ FloatingParseQueue
  │    ├─ DouyinWebViewEngine（1×1 隐藏 WebView）
  │    ├─ ParseController → DouyinDetailNormalizer
  │    └─ DownloadService.enqueue → 等待任务终止
  └─ FloatingAssistantScheduler → JobScheduler 周期看护

DouyinAccessibilityService
  ├─ 识别抖音/抖音极速版前台窗口
  ├─ 自动点击“分享 → 分享链接”
  └─ 复制成功提示 → 触发剪贴板读取
```

### 前台服务与通知

- `FloatingAssistantService` 使用 `foregroundServiceType="specialUse"`，并在
  `AndroidManifest.xml` 中声明 `android.app.PROPERTY_SPECIAL_USE_FGS_SUBTYPE="floating_assistant"`。
- Android 14+ 需要 `FOREGROUND_SERVICE_SPECIAL_USE` 权限；低版本按普通前台服务启动。
- 常驻低优先级通知显示前台状态、解析/下载进度和“关闭浮球”动作。Android 13+ 需要通知权限。
- 通知使用 `specialUse` 类型，是系统允许长期显示悬浮窗业务的通知凭证。

### 后台剪贴板限制

Android 10+ 默认禁止后台应用读取剪贴板；仅靠前台服务仍可能返回空。
`ClipboardFocusReader` 会在需要时创建一个 1×1 的可聚焦悬浮窗，短暂成为焦点窗口后读取剪贴板，
然后移除并把焦点还给抖音。它只在自动点击分享成功、或检测到“链接已复制成功”的无障碍提示时使用，
不会在后台持续轮询。若设备/系统仍拒绝，浮球会提示用户手动打开“输入链接”。

### 保活

- `FloatingAssistantScheduler` 注册 15 分钟周期、`persisted` 的 `JobScheduler` 任务作为看护；
  系统回收进程后，下一次周期检查会尝试重新启动服务。
- `BootCompletedReceiver` 在开机/应用更新后重新注册任务并尝试恢复服务。
- `MainActivity` 启动或恢复时也会检查设置并恢复浮球服务。
- OEM 的电池管理、自启动限制、强制停止仍可能阻止恢复；设置卡片提供“忽略电池优化”入口。
  应用更新后部分系统会关闭无障碍服务，需要在系统设置中重新开启；浮球会显示未授权提示。

## 权限

| 权限 | 用途 | 是否可自动申请 |
|---|---|---|
| 悬浮窗（SYSTEM_ALERT_WINDOW） | 显示浮球、输入框、隐藏解析窗口、焦点剪贴板 | 跳转系统设置，由用户授予 |
| 无障碍服务 | 识别抖音前台、自动点击分享/分享链接 | 必须由用户在系统无障碍设置手动开启 |
| 通知（POST_NOTIFICATIONS，13+） | 前台服务常驻通知 | 运行时申请；拒绝后服务仍可运行但通知不可见 |
| 忽略电池优化（可选） | 降低被 OEM 回收概率 | 跳转系统授权页 |
| 开机广播 | 开机后恢复看护任务 | 安装时声明 |

无障碍服务配置允许读取当前窗口内容并执行手势/点击；它只处理抖音和抖音极速版窗口，
不使用网络、不导出页面内容。用户可以随时在系统设置关闭。

## 失败与恢复

- **无障碍未开启**：轻享模式仍可用；连播模式会提示并打开无障碍设置。
- **剪贴板读取失败**：先尝试普通读取，再使用焦点窗口；仍失败时提示“输入链接”。
- **抖音分享面板改版**：找不到“分享链接”时提示，不会反复误点；需要更新 `DouyinAccessibilityService`。
- **安全验证/登录**：安全验证自动展开解析页面；登录页不自动展开，面板提供“打开登录页面”。
- **链接过期**：自动下载失败后由 DownloadService 标记 `NEEDS_REFRESH`，需要回 App 重新解析。
- **进程被杀**：队列和当前滑动页面状态丢失；看护任务和 App 启动时会尝试恢复浮球服务。
- **应用更新**：部分设备会关闭无障碍服务；需重新开启。

## 测试要点

1. 授予悬浮窗/通知/无障碍后，浮球能在桌面、抖音和其他应用上显示。
2. 轻享模式复制新链接，浮球自动出现解析提示，点击后进入 DouyinKit 解析页并显示结果。
3. 浮球“输入链接”可用，悬浮输入框可输入/粘贴并解析。
4. 连播模式点击“分析当前视频”能自动点击分享并复制链接；焦点剪贴板补救成功。
5. 隐藏 WebView 解析完成；面板显示阶段/进度（不显示标题/模式/作品标题）；不会切回 App。
6. 自动下载按默认清晰度/图集开关执行，结果进入相册；重复内容跳过。
7. 当前任务未完成时再次点击“分析当前视频”，新链接自动复制并加入队列，完成后执行；不出现“下一个”按钮。
8. 安全验证时展开验证页面；登录页不自动展开。
9. 杀进程后 App 启动/JobScheduler/开机广播的恢复行为；OEM 限制下至少给出提示。
10. 关闭浮球后通知、悬浮窗、前台服务全部停止。
11. 点击浮球只打开操作环；全部按钮为图标，分析按钮在默认 0° 时位于正上方；拖动浮球时按钮跟随。
12. 浮球可拖到屏幕边缘，操作环自动收起；点击边缘浮球会在约 220ms 内移回安全位置并展开。
13. 浮窗可独立拖动/缩放，默认 280×112dp，最小可到约 150×64dp；最小宽高和按钮距离/角度设置生效。
14. 状态点在抖音前台为绿、桌面/DouyinKit 为灰；打开/关闭浮窗不改变颜色；未开无障碍时为空心灰环。
15. 毛玻璃/半透明/完全透明/纯色、背景色、磨砂强度、浮球大小/透明度、按钮布局、浮窗最小尺寸、
    休眠时长和剪贴板显示设置在重启后保留。
16. 默认 45 秒无操作后浮球移到最近边缘并降低透明度；点击唤醒、移回并展开操作环；任务/浮窗/输入框打开时不休眠。
17. 配置 JSON 导出/导入和 ZIP 记录导出/导入有进度、错误提示，导入后列表刷新；更高 schema 拒绝导入。
