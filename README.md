# DouyinKit

DouyinKit 是一个**纯本地运行**的 Android 工具：粘贴抖音分享链接或文案，解析视频、图文图集、LivePhoto 和 BGM，并保存到系统相册、音乐和下载目录。

开发者：[atqiyu](https://github.com/atqiyu) · GitHub 仓库：[atqiyu/DouyinKit](https://github.com/atqiyu/DouyinKit) · 开源许可证：[MIT License](LICENSE) · [最新 Release](https://github.com/atqiyu/DouyinKit/releases/latest)

- 不依赖电脑、Node 服务或任何云端解析 API
- 不包含分析统计、广告或账号上传
- 解析、历史、收藏、标签和 Cookie 都只保存在本机

> **用途声明**：本项目仅用于个人学习，以及备份你已获得授权的内容。解析依赖抖音公开页面，可能随页面改版或风控失效；请遵守抖音服务条款和内容版权，不要用于批量抓取、商业分发或传播他人作品。

## 功能

- 分享文案/剪贴板识别抖音链接，本地解析 `v.douyin.com` 短链
- 安全验证自动展开：只有滑块/拼图/验证码等真实安全验证会自动显示 WebView；登录页和普通慢页面不会自动展开，登录提示可手动点“显示页面”
- 首页采用渐变 Hero、真实应用图标、四个功能卡片和轻量入场动画；链接输入框支持一键清空
- 首次启动显示用户协议与免责声明卡片，勾选同意后才能继续使用
- **Kit 浮球**：可选前台悬浮球，支持轻享模式（剪贴板/悬浮输入框解析）和连播模式（无障碍自动点击抖音分享 → 分享链接、隐藏 WebView 解析、自动下载、队列）；点击浮球后全部操作按钮以图标环绕浮球弹出，分析按钮在正上方且不再带文字，“下一个”已移除；队列繁忙时仍可直接点“分析当前视频”自动复制并加入队列；浮窗与浮球分离，可拖动/缩放，支持毛玻璃/半透明/完全透明/纯色、颜色、不透明度、磨砂强度、按钮距离/整体旋转、浮球大小/透明度和浮窗最小尺寸设置；浮球可拖到屏幕边缘，点击边缘时自动平滑移回安全位置；一段时间无操作后自动移到最近边缘并降低透明度，点击唤醒；面板背景只在自身区域绘制，不模糊屏幕其他区域；外圈进度环反馈解析/下载进度。使用 specialUse 前台服务、常驻通知和 JobScheduler 看护，详见 [docs/FLOATING_ASSISTANT.md](docs/FLOATING_ASSISTANT.md)
- 资料库收藏与下载页同步：下载页顶部为“全部 / 收藏 / 自定义合集”，不再显示“未分类”；资料库收藏后作品即时出现在下载页收藏筛选
- 资料库/下载页封面与作品预览图使用轻量渐显动画（约 240ms，仅 GPU 图层动画，不触发重新布局）
- 设置页按“全部 / 下载 / 浮球 / 外观 / 隐私 / 备份 / 关于”分类，新增浮球外观、配置导出/导入和解析/下载记录导出/导入
- 配置备份 JSON 包含 schema、versionCode/versionName、导出时间和全部设置；记录备份 ZIP 包含 manifest.json、awemes.jsonl、downloads.jsonl，带进度与错误/跳过统计
- 视频：多码率档位、无水印直链、H.264/H.265 标识；默认清晰度支持“最高清晰度”、4K、1080P 等，选择“最高”时自动取作品中最高分辨率，同分辨率优先 H.264
- 图文：全部图片、LivePhoto 动图 MP4、可选 BGM、可选 ZIP 打包；结果页支持缩略图多选部分图片下载，长按任意图片可直接带着该图进入选择器
- BGM：优先 `music.play_url` 直链；缺失时用 `MediaExtractor` + `MediaMuxer` 从视频无损提取音轨为 M4A
- 下载：直链/镜像/`playApi` 容错、Range 续传、MP3/MP4/WebP/JPEG/PNG 等 magic 校验、前台服务通知、取消和重试
- 清晰度支持多选，一次下载多个档位；结果页实时显示下载进度、速度和完成状态
- 预览：Media3 ExoPlayer 播放视频/动图/本地 BGM，图片左右滑动与双指缩放；下载页按作品聚合，可切换网格/列表，并从作品预览查看作者、描述、统计、作品 ID、发布时间和每个文件的尺寸/格式/帧率/编码/时长
- 抖音风格播放器：无默认五键控制条，单击暂停/继续、底部平滑进度线可拖动；详情/分享/打开集中在右上角。左下角作品信息可一键渐隐/渐显；隐藏时顶部标题、退出按钮、操作按钮、图片页码和动图提示全部隐藏，只保留更淡的显示/隐藏按钮
- 视频进度条提供 58dp 纵向拖动热区；拖动时进度线与游标变为更亮的红色并加粗、带发光效果，松手后平滑恢复
- 图文作品预览时，若作品带有 BGM，会自动循环播放；播放 LivePhoto 动图时 BGM 继续循环（动图原声静音，避免重叠）；切换到视频/音频预览时暂停，返回图片后继续
- LivePhoto 在图片预览中直接点击即可循环播放，播放中再次点击不暂停，仍可左右滑动切换图片和正常返回
- 下载卡片长按打开内容选择：查看文件级详情、在作品预览中分析、移动到合集，或用系统应用打开
- 下载记录管理：右上角入口可按作品全选/部分选择（长按作品选择单张图片、视频清晰度、BGM、ZIP 等），确认时可选择是否同时删除本地文件
- 下载页排序：最近/最早下载、文件最大、文件最多、按作品标题、按作者昵称，选择保存在 DataStore
- 下载页合集：新建、重命名、删除合集；长按作品“移动到合集”；顶部合集芯片筛选，作品卡片显示所属合集；删除合集只解除分类，不删除作品或本地文件；未分类筛选已由“收藏”替代
- 重复下载识别：按作品的具体视频清晰度、图片、动图、BGM、封面和 ZIP 判断，可选择跳过重复、覆盖原有（新文件成功保存后删除旧文件并更新下载时间）或重复下载
- 资料库：解析历史、收藏、标签、搜索与筛选、多选删除；可重新解析过期链接；从资料库打开的结果页支持系统返回键/侧滑手势回到资料库
- 资料库/下载页：搜索改为图标展开，排序、合集和日期筛选整合为控制条；标题/作者按首字符分组、最近/最早按日期分组、大小/文件数按区间分组；滚动时显示渐变进度胶囊和百分比
- 下载搜索：匹配标题、作者、标签、合集名称、作品 ID、BGM 名称；支持按下载日期（日历）查找作品，并与搜索、合集和排序组合使用
- 性能：解析历史/下载历史解码移出主线程；封面固定尺寸、滚动期间延迟加载新封面；正式发布包启用 R8，真机快速滑动 90 分位约 11–12ms
- 首页最近解析可直接打开或跳转资料库；剪贴板监听常驻主页层，启动、回到前台和前台复制新链接时立即识别，切换标签不会重复触发或丢失已有横幅
- 首页/资料库/下载/设置保留各自状态和滚动位置，切换使用短时淡入/位移过渡；结果页和作品预览使用独立滑入动画
- 下载页网格/列表与排序方式保存在 DataStore，重启后保持
- 设置：默认清晰度（最高/4K/1080P/720P/540P）、优先 H.264、LivePhoto/BGM/ZIP 默认项、主题、动态取色、剪贴板识别、历史保留与隐私清理
- Android 7（minSdk 24）到 Android 16（targetSdk 36）；Compose Material 3，支持深色主题

## 构建

环境：

- JDK 17
- Android SDK：`platforms;android-36`、`build-tools;36.0.0`（AGP 也会自动安装 35.0.0）
- 可访问 Google Maven / Maven Central（仓库已配置阿里云镜像，官方仓库作为回退）

```bash
./gradlew assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
```

Windows 下可直接使用 `gradlew.bat`。

- **推荐安装 release 包**：启用 R8 与资源压缩，APK 约 3.44 MB，滚动和冷启动明显优于 debug 包。当前个人 sideload 发布包使用标准 Android debug keystore 签名（与 1.3.0 安装包同一密钥），因此可直接覆盖升级；如果用于公开分发，请改为私有 release keystore，且不要把密钥提交仓库。
- `assembleDebug` 仍可用于日常调试，约 26 MB、未混淆。
- 后续开发/AI Agent 构建 APK 前请先阅读 [R8 构建与性能提醒](docs/R8_BUILD_REMINDER.md) 和根目录 [AGENTS.md](AGENTS.md)，不要把 debug 包当作发布/性能包。

## 使用

1. 在抖音中分享作品 → 复制链接，或直接复制分享文案；也可以从浏览器/其他 App 选择 DouyinKit 打开抖音作品链接。
2. 打开 DouyinKit，粘贴到首页输入框；剪贴板检测开启时，回到 App 会自动出现“检测到抖音链接”横幅。
3. 点击解析。首次可能需要 10–20 秒；如果页面出现滑块/拼图等安全验证，应用会自动展开 WebView 并提示“请完成页面验证”，完成验证后自动继续。若只是登录页，应用不会自动展开，会提示可点“显示页面”手动登录。
4. 在结果页预览、选择清晰度、下载视频/图集/BGM/封面，或收藏、加标签、重新解析。图文作品可下载全部图片，也可点“选择图片”在缩略图网格中多选；长按任意图片会直接带着该图进入选择器。
5. 打开底部“下载”标签页查看进度和已完成文件。同一作品的文件会自动归为一组，可切换网格/列表、按下载时间/大小/文件数/标题/作者排序；长按作品可移动到自建合集，顶部芯片按“全部 / 收藏 / 自定义合集”筛选。点卡片打开作品预览，右侧“详情”查看作品信息和每个文件的尺寸、编码、帧率、时长等。

### Kit 浮球

设置 → Kit 浮球 → 启用浮球。首次使用会依次引导授予悬浮窗、通知、无障碍和可选的电池优化：

- **轻享模式**：点浮球读取剪贴板链接，或点“输入链接”在悬浮输入框粘贴；确认后回到 DouyinKit 解析页。检测到新链接时浮球会变成粉色圆点并弹出解析提示，不自动下载。
- **连播模式**：需开启无障碍。在抖音/抖音极速版播放页点浮球 → “分析当前视频”，浮球自动点击“分享 → 分享链接”，从剪贴板取得链接后在隐藏 WebView 中解析，不切回 App；可在设置中开启“连播自动下载”，按现有默认值自动保存并在浮球中显示进度。上一个作品未完成时再次点“分析下一个”会进入等待队列。
- 安全验证会自动展开验证页面；登录页只提示手动打开。浮球只用于个人设备和已授权内容，不提供验证码破解。完整说明见 [docs/FLOATING_ASSISTANT.md](docs/FLOATING_ASSISTANT.md)。

### 备份与恢复

设置 → 备份：可单独导出/导入配置 JSON，或导出/导入解析与下载记录 ZIP。配置包含全部设置、schema 和版本信息；记录 ZIP 包含作品信息、下载记录和本地文件 URI/路径，不包含媒体文件本身。导入有进度、跳过与错误提示；同名记录按主键覆盖，跨设备导入后本地路径可能失效。

保存位置：

- 视频：`Movies/DouyinKit/`
- 图片与 LivePhoto：`Pictures/DouyinKit/<标题>_<作品ID>/`
- BGM：`Music/DouyinKit/`
- ZIP：`Downloads/DouyinKit/`

## 解析原理（简述）

```
分享文本
  → LinkExtractor 提取抖音 URL
  → OkHttp 不跟随重定向读取短链 302 Location
  → 隐藏 WebView（桌面 UA）打开 www.douyin.com/video/<id>
  → document-start 注入 hook，拦截 /aweme/v1/web/aweme/detail/ 响应
  → JS 侧裁剪 JSON，通过 WebMessage/JavascriptInterface 回传
  → Kotlin 归一化：视频档位/封面/作者/统计/图集/LivePhoto/BGM
  → 图文再打开 /note/<id>，从 React 页面模型补齐 LivePhoto 与播放信息
  → 结果页；下载直连 CDN（Referer + 桌面 UA）
```

详细实现与调试方式见 [docs/PARSING.md](docs/PARSING.md)，整体结构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 隐私与安全

- 无第三方分析 SDK；除抖音页面与 CDN 外不发起网络请求
- Cookie 仅保存在 WebView 本地，可在设置中一键清除
- 下载 URL 限制为抖音/字节 CDN 域名，拒绝内网、IP 字面量和未知重定向目标
- 解析历史存放在 Room；下载历史存放在 Room；均可清除
- 浮球仅在用户主动开启后运行；无障碍服务只处理抖音/抖音极速版窗口，用于本机前台识别和分享点击，不上传页面内容
- `allowBackup=false`，并配置了排除全部内容的备份规则
- 不在日志中输出 Cookie 或完整签名 URL（诊断仅显示 host/path）

## 已知限制

- 只支持公开作品；私密、登录可见、直播、主页、合集不支持
- Kit 浮球的连播模式必须手动开启无障碍服务，且依赖抖音/抖音极速版当前版本的“分享 → 分享链接”界面；抖音改版后可能需要更新无障碍选择器
- Android 10+ 对后台剪贴板有限制；浮球会在分享复制后短暂获取焦点读取，若设备仍拒绝则提示手动输入
- 浮球队列只保存在进程内，服务被杀后队列丢失；OEM 电池/自启动管理可能阻止 JobScheduler 恢复，建议在设置中忽略电池优化
- 记录备份只包含记录和本地文件 URI/路径，不包含媒体文件；跨设备导入后文件位置可能失效
- 浮窗磨砂是面板内部绘制的材质，不采样屏幕背后内容，也不依赖系统跨窗口模糊；因此不会出现部分 OEM 的整屏模糊，但也不是真实背景模糊
- 边缘拖动、自动回移和休眠使用 220–320ms 的窗口位移动画；非常老旧的设备上窗口动画可能略慢，可在设置中关闭自动休眠
- 状态点依赖无障碍服务识别前台；未开启时显示空心灰环，设置页提供授权入口
- 应用更新后部分系统会关闭无障碍服务，需要重新开启
- 解析成功率取决于抖音 WebView 页面与风控；不是官方 API，页面改版可能需要更新 `hook.js` / `page_model.js`
- 播放地址约 1 小时过期；后台下载不会启动 WebView 自动重新解析，过期后需回到前台重新解析
- H.265 文件可以下载，但部分设备相册/播放器无法解码；默认 1080P 优先 H.264，选择“最高清晰度”时优先同分辨率 H.264，若作品没有 4K H.264 则会选 4K H.265
- 重复下载检测基于本机下载记录；若用户在系统相册中手动删除了文件但记录仍在，App 仍会把它视为已下载。可先在下载管理里清理记录
- “覆盖原有”只在新下载完整成功且没有文件失败时才删除旧文件；部分失败会保留旧文件，避免内容丢失
- LivePhoto 保存为“静态图 + 动图 MP4”，不合成系统动态照片
- Android 10+ 限制后台读取剪贴板；App 会在启动、回到前台以及 App 处于前台时检测剪贴板变化，完全进入后台后由系统阻止读取，不会也无法在后台轮询。回到前台时会补读最新内容。
- 未在 Android 7 真机上运行验证，仅通过 minSdk 代码审查和 Lint；建议在目标设备上回归
- 未上架 Google Play；推荐 sideload R8 优化后的 release APK。当前发布包为方便覆盖升级仍使用 debug keystore 签名，不适合作为公开商店分发包
